# Laporan eksekutor ZidWindowsApps 1.2.1 beta

21 November 2026 · Windows x64 · Tag lokal `v1.2.1-beta` · Commit `173e41f8e813`

## Ringkasan

Instalasi 1.2.0 di PC Zidna berhasil diperbarui ke 1.2.1 beta. Pengujian mencakup sembilan halaman Fluent, UI lama, pilihan Downloads, serta penyimpanan pengaturan. Pemeriksaan sesudah pemasangan mencocokkan seluruh 463 file publish dan enam file data pengguna. Zidna menyetujui finalisasi beta dengan cakupan perangkat dan uji uninstall yang tercantum di bawah.

Waktu build merupakan satu pengukuran pada setiap checkout bersih dengan SDK dan cache NuGet mesin yang sama. Waktu tersebut mencakup kompilasi, di luar restore, publish ReadyToRun, dan kompresi NSIS. Angka installer dan publish awal diambil dari paket 1.2.0 yang tersimpan. Hash DLL paket awal sama dengan instalasi awal. Tidak ada paket NuGet eksternal dalam kedua proyek Windows. Audit paket aplikasi tidak melaporkan kerentanan dari feed yang dikonfigurasi.

## Sumber, resource, dan perapian kode

```text
ZidWindowsApps/
  Program.cs, ZidWindowsApps.csproj, build.ps1, build-linux.sh
  Infrastructure/       AppPaths, AppSettings, log dan validasi path
  Models/               model aplikasi
  Services/             layanan Windows
  Resources/            MainWindow.xaml dan Styles.xaml untuk UI lama
  UI/                   App dan MainWindow
    Fluent/             shell, styles, pratinjau Debug
      Live/             sembilan modul produksi
  tools/FluentReview/    uji interaksi WPF
  docs/ui-migration/     dokumentasi dan tangkapan layar migrasi
  installer/            definisi NSIS dan pembuat daftar uninstall
  launcher/             launcher native, manifest dan ikon
  refs/                 petunjuk referensi untuk build Linux
```

- ICO berisi ukuran 16, 24, 32, 48, 64, 128, dan 256. Kompresi ulang PNG di dalam ICO menghemat 126 byte. Kompresi ulang 50 PNG dokumentasi menghemat 513.763 byte. Data hasil dekompresi setiap aliran gambar diverifikasi sama. **Total penghematan aset 513.889 byte**, termasuk dokumentasi di luar installer.
- Inventaris hash tidak menemukan file sumber identik yang perlu digabung. Dua resource bernama Styles.xaml dimuat dari namespace dan entry point berbeda. PreviewData.json dipakai oleh Debug. Semua dipertahankan. Tidak ada font, audio, atau paket locale aplikasi tersendiri. Resource bahasa runtime .NET tetap dibundel.
- Formatter diterapkan dalam commit khusus untuk proyek aplikasi dan alat review. Tidak ditemukan penanda TODO/FIXME/HACK dalam sumber C# yang diperiksa. Console.WriteLine alat review dipakai untuk status pengujian. Tidak ada dependency atau fitur yang dihapus dan tidak ada perubahan format pengaturan. Skrip paket mengecualikan simbol debug. Publikasi akhir memuat empat resource XAML, tanpa JSON pratinjau, PDB atau folder _trash.
- Pemeriksaan pola kredensial pada 61 file teks sumber, konfigurasi, dan dokumentasi tidak menghasilkan temuan. Dari 463 file publish, 460 identik dengan file paket 1.2.0. Tiga file yang berubah adalah executable, DLL aplikasi, dan deskripsi dependensinya.

## Ditunda dan penyesuaian plan

- Uninstall tidak dijalankan di PC ini, sesuai instruksi Zidna. Uji lanjutan pada VM sekali pakai perlu memeriksa uninstall sesudah upgrade, pelestarian file tambahan, dan pilihan penghapusan data.
- Windows 10, high contrast, screen reader, perpindahan antar-monitor, serta DPI fisik 125%, 150%, dan 200% memerlukan pengujian tambahan. Operasi yang mengubah sistem nyata, termasuk membuang isi Recycle Bin, menghapus aplikasi pihak ketiga, menjalankan perbaikan sistem, serta pembuatan dan penghapusan jadwal aktif, dicakup sebagian lewat fixture atau dialog batal.
- Proyek di Desktop sudah memakai Fluent dan cocok dengan distribusi terpasang. Riwayat Git lokal diawali dengan snapshot sumber 1.2.0. Tag cadangan `pre-v1.2.1-snapshot` dan branch `chore/cleanup-v1.2.1-beta` disimpan. Setiap clean build memakai checkout baru untuk mempertahankan distribusi 1.2.0.
- Stack aktual adalah C# / WPF dengan dukungan Windows Forms untuk tray dan dialog, serta SDK .NET, NuGet dan NSIS. Release Windows x64 memakai ReadyToRun, self-contained. Tidak ditemukan auto-updater pada jalur distribusi ini. Build Linux dan ARM64 belum diuji dalam eksekusi ini.
- Pengaturan dilindungi oleh perbandingan hash lokal. Zidna telah menyetujui cakupan uji beta di atas. Permintaan perilaku layar penuh ditangani terpisah setelah patch ini.
