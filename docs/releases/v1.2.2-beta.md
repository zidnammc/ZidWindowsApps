Bug-fix beta for the Fluent UI introduced in 1.2.x.

### Fixed

- **Empty Recycle Bin always failed** with "Ukuran Recycle Bin tidak dapat dibaca". The Recycle Bin query struct had the wrong size on 64-bit Windows (`Pack = 1`, 20 bytes instead of 24), so Windows rejected every call with `E_INVALIDARG`.
- Emptying an already-empty Recycle Bin no longer shows an error.
- **Dashboard showed "Belum dipindai" right after a cleanup.** The card now shows your last cleanup (size, files, time, scheduled or manual), and it survives restarts.
- Freed space was under-counted when a batch failed part-way; cancelled cleanups now still record what was done.
- The "Empty Recycle Bin" button is always available on the Cleanup page (it used to disappear after a restart).
- The tray uses the app icon, and restoring from the tray returns to the previous (maximised) size.
- Labels in button rows no longer touch the neighbouring button.

### Install

Download **`ZidWindowsApps-Setup-1.2.2-beta-win-x64.exe`** below (self-contained, Windows 10/11 x64, no .NET runtime needed). Installing over 1.1.x or 1.2.x keeps your settings. The installer is not code-signed, so SmartScreen may ask you to confirm.
