# Perubahan ZidWindowsApps

## v1.2.1 beta.1 — 21 November 2026

- Aplikasi langsung membuka jendela utama dalam keadaan dimaksimalkan. Taskbar, judul, serta tombol perkecil, pulihkan, dan tutup tetap tersedia, termasuk saat memakai UI lama.

## v1.2.1 beta — 21 November 2026

### Diperbaiki

- Di Pembersihan, memilih semua kategori tetap mengharuskan file Downloads dicentang satu per satu. Membatalkan seluruh pilihan juga membatalkan pilihan Downloads.
- Pengaturan memakai file sementara tersendiri setiap kali disimpan. Pengaturan versi 1.2.0 tetap dapat dibaca.
- Uninstaller paket Windows mandiri hanya menghapus file aplikasi yang tercantum saat paket dibuat. Folder instalasi yang masih berisi file tambahan dipertahankan.

### Dirapikan

- Ikon aplikasi dan gambar dokumentasi dikompresi tanpa mengubah piksel. Daftar ukuran ikon tetap lengkap.
- Nama installer, informasi versi Windows, dan judul jendela menampilkan versi beta.

### Diketahui / Ditunda

- Pengujian uninstall menyeluruh memerlukan lingkungan Windows terpisah. Cakupan perangkat, DPI, dan pengujian tersedia dalam laporan eksekutor.
